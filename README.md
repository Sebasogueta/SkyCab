# SkyCab - Connecting Pilots and Passengers

![SkyCab Logo](images/logo.png)

## ✈️ Introduction
SkyCab is an innovative platform designed to connect licensed pilots with aviation enthusiasts and travelers looking for unique flying experiences. The app allows pilots to accumulate flight hours while offering affordable air travel to users.

## 🌟 Features
- **User Authentication**: Secure login and registration via Firebase Authentication.
- **Flight Search**: Find flights based on departure, destination, and date.
- **Favorites Management**: Save and manage preferred flights.
- **Pilot and Passenger Profiles**: Dedicated interfaces for pilots and users.
- **Flight Booking System** (🚧 *Not fully implemented yet*).
- **Rewards System** (🚧 *Planned for future updates*).

## 🔧 Technologies Used
- **Frontend:** Kotlin (Jetpack Compose) for Android, Spring Boot (planned for web version).
- **Database:** Firebase Firestore for storing flight and user data.
- **Authentication:** Firebase Authentication for secure user login.
- **API Integration:** OpenWeatherMap & Tomorrow.io for weather data (future enhancement).

## 🚀 How It Works
1. **Sign Up/Login** – Users and pilots register and log in securely.
2. **Search for Flights** – Users can search for available flights.
3. **Book a Flight** – (🚧 *Feature in progress*).
4. **Pilot Interaction** – Pilots can update flight details and manage bookings.
5. **Enjoy the Flight!**
